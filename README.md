# 🏥 Hospital Management System in C

This is a simple **Hospital Management System** built using the **C programming language** as part of the **Programming Fundamentals** course project.

The system is a **console-based application** that allows users to manage patient admissions, discharges, and doctor records using basic file handling and structures in C.

---

## 📋 Features

✅ Admit new patients  
✅ View all admitted patients  
✅ Discharge a patient by ID  
✅ Add new doctors  
✅ View all doctor records  

---

## 🛠️ Technologies Used

- Language: **C**
- Concepts: **Structures**, **File Handling**, **Switch Statements**, **Loops**
- Platform: Windows (Tested on **Dev C++**)


---

## 🧑‍💻 How to Run

1. Open the project in any C IDE like **Dev C++** 
2. Make sure to **enable compiler support for legacy headers** (e.g., `conio.h`)
3. Compile and run `hospital.c`
4. Follow the on-screen menu to interact with the system.
